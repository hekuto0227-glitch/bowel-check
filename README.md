# 排便チェック管理システム

GitHub Pagesなどの静的ホスティングで動作する、ブラウザ保存型の排便チェック管理システムです。

## 主な機能
- 利用者を後から追加・編集
- 今日の日付を自動入力
- 未記録＝本日の排便なしとして表示
- 排便あり＝○、保存すると0日目
- 前回排便からの日数を自動計算
- 3日目・4日目の注意表示（設定変更可能）
- 緩下剤・浣腸の利用者別設定
- ブリストルスケール
- 形状を「硬」「普通」など簡潔に入力
- その他・備考の自由入力
- 女性の月経を簡単管理
- 一覧・検索・絞り込み
- CSV出力
- A4（個人）/A3（全員）のExcel互換帳票出力
- JSON完全バックアップ／復元
- テストデータモード
- データバージョンを維持した移行設計

## データ保護
利用者データはGitHub上のコードとは別に、ブラウザのlocalStorageへ保存します。
コードをGitHubで更新しても、アプリが既存の保存データを初期化しない設計です。

ただし、ブラウザのデータ消去・端末変更・サイトデータ削除などでは復元できなくなる可能性があります。
本番運用では「完全バックアップ」でJSONをPC等へ定期保存してください。

## GitHub Pages
リポジトリの Settings → Pages → Deploy from a branch → main / root を選択して公開できます。

## 注意
医療・福祉現場で実際の個人情報を扱う場合は、所属先の情報セキュリティ規程、端末管理、バックアップ方針、アクセス権限などを確認してください。
